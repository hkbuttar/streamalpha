# StreamAlpha Frontend

React + TypeScript + Vite dashboard for StreamAlpha. See the [repo root README](../README.md#frontend) for what this is, how it's verified, and full setup instructions.

```bash
npm install
npm run dev      # http://localhost:5173, requires backend/main.py running (see root README)
npm run build     # type-checks then builds to dist/
npm run lint      # oxlint
```
